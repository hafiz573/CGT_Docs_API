BooLua (modded)

Two builds, one site

Native (CGT Ori) is the stock V1.50 API from the APK. BooLua is the mydll-patched build: the same native API plus the loader's added functions and overrides. Switch with the Build menu.

Verified against the game

The authoritative list of 108 names and their namespaces comes from a live in-game _G dump (hash 19601d21), identical on PC and Android. Nothing is guessed about what exists.

Namespaced surface

Globals plus seven namespaces - Client, Entities, Input, Proton, Render, Script and UI. Parameter types and return-table fields are reverse-engineered from the binary; structs and enums included.

Unofficial & inferred

This is community documentation. Names and namespaces come from a live _G dump; parameter types and return fields are reverse-engineered from the binary and the one-line descriptions are inferred. Verify against your own build before relying on any detail.
